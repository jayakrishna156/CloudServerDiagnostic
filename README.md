# Cloud Server Diagnostic

A Bash-based Linux server health and network diagnostic tool.

## Features

- Hostname and user information
- IP address information
- Routing information
- Disk usage
- Memory usage
- CPU/load information
- SSH service status
- Listening ports
- Internet connectivity
- DNS resolution

## Technologies

- Linux
- Bash
- Networking
- SSH
- Git

## How to Run

```bash
chmod +x server_check.sh
./server_check.sh
